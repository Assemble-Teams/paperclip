Use this project as a template for one advisory engagement at a time.

Create engagement-specific projects from this pattern rather than mixing unrelated clients or providers into one shared project. Each project should state its intended outcome, success criteria, material constraints, current actions, decisions, evidence, and closure conditions.

Keep confidential client/provider data in the private company workspace, not in the public team package.
